# FOOD2U

Live site: https://food2u.onrender.com/

A simple JavaScript-based food ordering web application. This repository contains the source code for FOOD2U — a project that lets users browse menus, add items to a cart, and place orders. The project is primarily written in JavaScript.

## Features
- Browse restaurant menus and food items
- Add/remove items from a cart
- Place an order (depending on backend setup)
- Responsive UI for desktop and mobile

## Demo
Open the live site to try the application:

## Getting started
These instructions assume the project uses Node.js and npm (common for JavaScript projects). Adjust commands if the project uses yarn or a different setup.

1. Clone the repository

```bash
git clone https://github.com/Adwaitb-112/FOOD2U.git
cd FOOD2U
```

2. Install dependencies

```bash
npm install
```

3. Run the app

```bash
npm start
```

Note: If the project has a separate client and server, check their respective README sections or package.json scripts (for example: `npm run client` and `npm run server`).
